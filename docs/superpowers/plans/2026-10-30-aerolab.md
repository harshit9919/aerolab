# AeroLab Implementation Plan

> Use subagent-driven development for independent domains and review integration before completion.

**Goal:** Deliver an interactive 3D airflow workbench with editing and reproducible local experiments.
**Architecture:** React owns configuration and immutable recorded runs. Three.js owns rendering and interaction. Pure aerodynamic approximations are independently tested; IndexedDB persists records.
**Tech Stack:** React 19, TypeScript, Vite, Three.js, Vitest, Playwright.
**Spec:** ../specs/2026-10-30-aerolab-design.md

## Constraints

- Clearly label approximate physics and browser-local persistence.
- Follow shared src/types.ts; no paid services or solver backend.
- Do not mutate a saved run when live configuration changes.
- Keep all controls functional and keyboard labeled.

## Review focus

Malformed imports must show actionable errors; zero wind must yield zero force; reloaded runs must preserve geometry; paused simulation must freeze time; small screens must retain access to controls.

## Tasks

- [ ] Physics and catalog: src/lib/physics.ts and catalog.ts. Export DEFAULT_SETTINGS, MODELS, SCENARIOS, calculateMetrics(model,settings,time), flowVelocity(point,model,settings,time). Write tests for zero wind, squared velocity, yaw/scale and finite turbulent outputs.
- [ ] 3D engine: src/components/Viewport.tsx and lib/geometry.ts. Render model, orbit/zoom, flow modes and primitive editing gizmos. Export importModel(file), exportModel(model), buildModel(model). Validate files and normalize imports.
- [ ] Persistence: src/lib/storage.ts and exports.ts. Store/retrieve runs and models with IndexedDB, validate project JSON, export histories to CSV and all state to project JSON. Test round trips and corrupted inputs.
- [ ] Interface: src/App.tsx, styles.css and main.tsx. Build laboratory, geometry editor, saved run browser and comparison view with charts, condition controls and recording/playback state.
- [ ] Verification: Typecheck, unit suite, production build, browser workflow tests and screenshots. Review for data loss, misleading scientific claims and nonfunctional controls.
- [ ] Package and publish through Sites, or document exact blocker with a runnable local project.
